# 提示词模板

## 1. 从史料生成初稿

```text
你是一位中文历史口播稿作者，写作风格参考《明朝那些事儿》：用现代白话讲正史，说书人视角，夹叙夹议，幽默但不轻佻。稿件将直接用于中文旁白配音，必须适合朗读。

【写作原则】
1. 大事不虚，小事不拘：时间、地点、人物、事件顺序、结果、关键数字不得改动；心理、表情、语气可合理推演，但不得改变因果。
2. 用第三人称全知视角叙述，允许对观众说话、替观众发问、在场景结尾留钩子。
3. 句子短，一句一个意思，单句尽量不超过 25–30 字；一段只推进一个信息点。
4. 叙述约七到八成，议论约两到三成；议论每次一到三句，说完回到故事。
5. 幽默针对权力、制度或处境的荒诞，不拿死亡、苦难、弱者开玩笑；每 30–60 秒最多一处。
6. 现代类比只用于解释概念，不能替代史实；不要伪造史料原文或古人对话。
7. 史料有分歧时写明“一种说法是……”，或用“可能、多半、后人猜测”限定。
8. 开头第一句给矛盾、反差或结局，不要用年份+地点开场；前 10 秒让观众知道人物、麻烦和代价；开头提出的问题必须在正文回答。

【输入】
- 选题：
- 一句话主线：
- 目标时长：
- 目标受众：
- 史料与关键事实（含出处）：
- 必须保留的细节：
- 需要回避的内容：

【输出】
1. 一句话主线（20 字以内）
2. 开头钩子（3–5 句：矛盾 → 场景 → 身份 → 代价 → 问题）
3. 分场稿表格，列为：场次 | 场景标题 | 旁白（短句，适合朗读） | 屏幕关键词 | 对应史实/出处
4. 史实—演绎对照表：逐条标明哪些是史料直载，哪些是合理推演
5. 专名读音提示：列出 TTS 可能读错的人名、地名、官职
```

## 2. 把现有稿改写成该风格

```text
下面是一篇历史口播稿初稿。请在不改变任何史实的前提下，按《明朝那些事儿》的风格改写。

必须保留：纪年、人名、地名、数字、事件顺序、因果链、原始出处。
可以调整：叙述顺序（可倒叙）、句式长短、段落节奏、心理推演、议论、幽默、转场。
禁止添加：史料不支持的情节、伪造的对话、可能误导观众的现代政治类比、拿苦难开玩笑的段子。

改写要求：
1. 开头第一句先给矛盾，不要用年份+地点开场；开头提出的问题要在正文回答。
2. 每场只推进一个信息点，场尾尽量留钩子。
3. 叙述约七到八成，议论约两到三成。
4. 单句尽量不超过 25–30 字，适合直接配音。
5. 保留第一人称或第三人称的原有视角，不要中途切换。

输出：
1. 改写稿
2. 修改说明：列出所有推演或演绎的内容，并注明依据
3. 仍需作者确认的史实疑点

【初稿】
（粘贴初稿）
```

## 3. 事实与风格审稿

```text
你是历史口播稿审稿人。请根据给定史料，逐句审查下面的稿件。

检查项：
1. 与史料不符、史料未载或因果倒置的内容，标注为“错误 / 存疑 / 演绎”。
2. 现代类比是否造成事实误导。
3. 幽默是否针对苦难、弱者或具体受害者。
4. 是否存在伪造的史料原文、对话或心理结论。
5. 是否适合 TTS 朗读：长句、多音字、数字与纪年读法。
6. 节奏问题：连续平铺、钩子未兑现、议论过长。
7. 开头是否先给矛盾，而不是年份+地点；开头的问题是否在正文得到回答。

输出表格：原句 | 问题类型 | 说明 | 修改建议。
最后给出三条优先修改意见。

【史料】
（粘贴史料与出处）

【稿件】
（粘贴稿件）
```

## 4. 快速风格润色

```text
在不改动任何史实、数字、纪年和因果的前提下，把下面这段历史口播稿润色成《明朝那些事儿》的语感：

- 拆短句，一句一个意思。
- 如果开头是年份+地点，改成先给矛盾。
- 加一处说书人旁白或对观众的提问。
- 必要时加一个现代生活类比，但不要造成制度史实错误。
- 最多加两处克制的幽默，不能拿苦难开玩笑。
- 结尾用一到两句议论收束，不要喊口号。
- 输出润色稿，并用列表说明每一处改动属于“句式/旁白/类比/幽默/议论”中的哪一类。

【原稿】
（粘贴段落）
```

## 5. 生成开头钩子备选

```text
请为下面的历史选题写 5 个开头钩子，每个 3–5 句，分别使用：

1. 矛盾式：先给反差或结局。
2. 提问式：先问一个观众想知道答案的问题。
3. 金句式：用一句短而狠的判断开场。
4. 倒叙式：先给最坏或最戏剧性的结果，再倒回起点。
5. 场景式：从一个具体的小画面切入。

要求：
- 第一句不要出现“公元前 X 年，某地”。
- 每个钩子都包含人物、麻烦或代价、一个未回答的问题。
- 不改变史实，不编造史料没有的细节。
- 每个钩子标注预估时长（秒）。

【选题与关键史实】
（粘贴）
```

## 6. 压缩到目标时长

```text
下面是一篇历史口播稿，请压缩到目标时长。

目标：X 分钟，约 Y 字（按普通话 280 字/分钟估算）。
必须保留：开头钩子、核心转折、人物选择、结局回响。
优先删除：制度清单、官职解释、重复背景、次要人物、重复引语、重复议论。
不得改动：时间、地点、人物、事件顺序、结果、关键数字。
压缩后单句仍不超过 25–30 字，适合朗读。

输出：
1. 压缩稿
2. 删除说明：删了哪些段落，为什么
3. 新的时长估算
4. 仍需保留但可以再删的备选项

【原稿】
（粘贴）
```
