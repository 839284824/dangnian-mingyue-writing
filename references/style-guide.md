# 当年明月风格：完整写作规范

## 一句话定义

**用现代人的嘴，讲正史的事，带说书人的节奏，掺文人的感慨。**

底层公式：

**史料骨架 + 现代语言 + 心理推演 + 幽默调剂 + 主观感慨 + 章回钩子**

判断一段稿子像不像，看三点：能不能一口气读出来；有没有一个讲故事的“人”在带路；听完除了知道发生了什么，还能感到作者的态度。

## 七个风格要素

### 1. 现代白话转译

把文言、制度、官职翻译成现代人能秒懂的话，必要时用现代事物类比。

- 做法：先问“这句话换成今天的话怎么说”，再问“这个官职相当于今天的什么角色”。
- 例：`内阁大学士，说白了，就是皇帝的高级顾问团。`
- 边界：类比只用于解释概念，不能替代史实。避免“秦朝组织部”“明朝财政部”这类容易被当成正式建制的说法。
- 反例：直接照搬“擢为兵部尚书，总督军务”，观众听不懂，节奏也断。

### 2. 说书人视角

叙述者是全知的、有态度的“讲书人”，不是冷冰冰的档案复述机。

- 可以对观众说话：`你可能要问，他为什么不跑？`
- 可以替观众发问：`这时候，一个要命的问题摆在了桌面上。`
- 每场结尾留钩子：`可他没想到，真正麻烦的还在后头。`
- 常用转场：`事情要从三年前说起。`／`说到这儿，得先介绍一个人。`／`可惜，历史没有如果。`
- 注意：钩子要兑现。每 1–2 场抛一次悬念，下一场必须接住，不能只吊胃口。

### 3. 心理与动机推演

把“谁做了什么”补成“他为什么这么做、当时怎么想”。

- 可用句式：`他大概在想……`／`换成你，你怎么办？`／`这一刻，他面前其实只有两条路。`
- 推演必须能落到史料支持的处境上：身份、利益、性格、前文因果。
- 写人心，不等于写抽象人性。关键选择至少要有处境、利益、制度或前史中的一个支点；不要用“他天性多疑”“他生来贪婪”一句带过。
- 每写一个心理判断，追问一句：他当时的处境，允许他这么想、这么做吗？
- 不伪造史料原文，不写“史书没记载但我知道”的细节。
- 涉及关键心理判断时，用限定语：`很可能`／`多半`／`后人猜测`。

### 4. 幽默与反差

用现代词、错位感和冷幽默制造记忆点，但幽默是调料，不是主菜。

- 常见手法：现代职业类比、一本正经的夸张、宏大叙事与生活细节的反差。
- 频率：大约每 30–60 秒一处，连续抛梗会稀释严肃感。
- 夸张只加在比喻、节奏和反问上，不加在事实和苦难细节上；夸张之后要接回具体史实。
- 红线：不拿死亡、酷刑、饥荒、平民苦难开玩笑；悲剧高潮处零玩笑。
- 网络梗慎用：优先选三五年后仍能听懂的词，避免一季就过期的缩写和热梗。

### 5. 夹叙夹议

叙事为主，议论为辅，作者随时可以跳出来说两句。

- 比例：叙事约七到八成，议论约两到三成。
- 议论要短：一到三句，说完就回到故事。
- 常用落点：人物选择的代价、制度的荒诞、历史的偶然与必然。
- 反例：连续三段抒情，故事停摆，观众会划走。

### 6. 人物戏剧化

把历史人物当角色写：有欲望、有弱点、有处境，忠奸之外更强调“他为什么这么选”。

- 给对手动机，不写脸谱化反派。
- 用“欲望—选择—代价”串人物弧线。
- 小人物也可以给一个镜头：一个士兵、一个太监、一个押运官，往往比帝王更能说明时代。
- 允许同情，但不替人物洗白；允许批判，但不辱骂。

### 7. 强节奏

这是口播稿，不是文章。节奏优先于辞藻。

- 一句一个意思，单句尽量不超过 25–30 字。
- 一段只推进一个信息点，段与段之间用时间、地点或问题切换。
- 多用动词和具体细节，少堆形容词。
- 数字要具体：`十万大军` 不如 `号称十万，实际能打的没那么多`——但后者必须有依据。
- 每 60–90 秒至少有一次转折、揭秘或选择，避免平铺直叙。

## 开头钩子

开头不要从年份和地点开始，从矛盾开始。

推荐结构：

1. **矛盾**（0–3 秒）：一句话给出反差、结局或选择题。
2. **场景**（3–10 秒）：用一个具体画面证明这个矛盾。
3. **身份**（10–15 秒）：让观众知道这个人是谁、他做了什么。
4. **代价**（15–20 秒）：给出输赢、生死或后果。
5. **问题**（20–30 秒）：留下这集要回答的问题。

三种常用写法：

**矛盾式**

> 一个制定法律的人，被自己的法律拦在了门外。
>
> 公元前 338 年，秦国边境，一家旅店……

**提问式**

> 你定了一条法，最后这条法把你逼上绝路，你信吗？
>
> 公元前 338 年，商鞅就遇上了。

**金句式**

> 商鞅这辈子干了两件事：
>
> 第一，把秦国变强；
>
> 第二，把自己逼死。
>
> 而且，第二件事，用的是他自己写的第一件事。

常见错误：

- 第一句写“公元前 X 年，某地，某人出生了”。年份和地点不是钩子。
- 先讲三代背景，再讲主人公。观众等不到那个时候。
- 抛出古语不翻译。`为法之敝，一至此哉` 后面要立刻接一句人话。
- 开头很响，正文不接。钩子提出的问题，后面必须回答。

## 单集结构模板

以 3–5 分钟、7–9 场为例：

| 段落 | 作用 | 参考时长 | 写法 |
| --- | --- | --- | --- |
| 1. 钩子 | 先给矛盾、反差或一道选择题 | 0–30 秒 | 第一句不要报年份和地点；用具体场景证明矛盾；结尾留问题 |
| 2. 出场 | 交代时间、地点、人物和处境 | 20–50 秒 | 回答“为什么是他”，给人物一个具体身份标签 |
| 3. 上升 | 事情顺利的一面，建立期待 | 40–70 秒 | 用具体事件推进，不写履历表 |
| 4. 转折 | “然而”出现，局面反转 | 30–60 秒 | 转折要有触发事件，不能靠旁白硬转 |
| 5. 抉择 | 把人物逼到选择题前 | 40–80 秒 | 列出可选的路和各自代价，让观众代入 |
| 6. 结果 | 交代结局，细节具体 | 40–70 秒 | 不急着评价，先把事实讲透 |
| 7. 回望 | 作者议论、金句收束 | 20–40 秒 | 回扣开场的问题；升华但不喊口号 |

如果做人物传记，可把 2–6 段循环两次：上升—转折—抉择—结果，形成“起、承、转、合”的双波浪。

## 句子层面的规则

- **一句一义**：长句拆短，避免“虽然……但是……而且……因此……”套四层。
- **先具体，后概括**：先给画面和动作，再给判断。`他连夜写了三封信` 比 `他内心十分焦虑` 有力。
- **少用“进行”“使得”“由于”**：改成“做了”“结果”“因为”。
- **称谓统一**：同一人物首次出现用“姓名 + 身份”，之后可用姓名、官职或绰号，但一集内别超过三种叫法。
- **纪年统一**：统一写“公元前 259 年”“正统十四年（1449 年）”这类格式，TTS 合成前确认数字读法。
- **多音字与专名**：交付时附一张读音表，标出 TTS 容易读错的人名、地名、官职。
- **适合朗读**：写完出声读一遍。读着喘不过气的句子，观众听着也累。

## 事实与演绎的边界

这是历史题材的底线，优先级高于风格。

1. **大事不虚**：时间、地点、人物、事件顺序、结果、关键数字，不得改动。
2. **小事不拘**：天气、表情、语气、具体对话可以推演，但不能改变因果和人物评价。
3. **三种安全的推演方式**：
   - 由处境推心理：`兵临城下，他多半一夜没睡。`
   - 由制度推行为：`按规矩，他必须先等兵部的批文。`
   - 由结果反推选择：`后来发生的事说明，他当时低估了对手。`
4. **争议要标出**：史料有分歧时写“一种说法是……另一种说法是……”，或保留限定语，不替古人下结论。
5. **现代类比不越界**：类比只帮助理解，不能被当成制度史实；避免用现代政治概念直接套古代。
6. **演绎要留痕**：初稿交付时附“史实—演绎对照表”，方便审稿和后期字幕把关。

## 幽默使用守则

- 笑权力、笑荒诞、笑制度，不笑苦难和弱者。
- 同一个笑点不重复，连续两场都有梗时，删掉一个。
- 死亡、屠杀、灾荒场景零玩笑。
- 现代梗优先选“生活常识型”，少用“网络流行型”。
- 幽默之后要能接回主线，不能为了抖机灵打断叙事。

## 自检清单

- [ ] 开头第一句是矛盾/反差/结局/选择题，不是年份+地点
- [ ] 前 10 秒让观众知道人物、麻烦和代价
- [ ] 开头提出的问题，正文有回答
- [ ] 一句话主线能写出来，且全片没有跑题
- [ ] 每场只推进一个信息点，场与场之间有明确转折
- [ ] 每 60–90 秒有一次悬念、揭秘或选择
- [ ] 所有心理描写都能对应史料处境，或已标注为推演
- [ ] 每个人物的关键选择，都能说出一个处境、制度或利益上的原因，而不是只靠性格标签
- [ ] 现代类比没有造成事实误导
- [ ] 夸张只作用于比喻、节奏和反问，没有改变事实或拿苦难细节开玩笑
- [ ] 没有拿死亡、苦难、弱者开玩笑
- [ ] 议论总时长不超过全片三成，没有连续抒情
- [ ] 人名、地名、纪年、数字已核对出处
- [ ] 专名读音表已附，长句已拆短
- [ ] 出声读一遍，没有读不顺或听不清的句子
- [ ] 结尾回扣开场，有态度但不喊口号

## 改写示例

**平铺直叙版**

> 公元前 259 年，嬴政出生于赵国邯郸。其父异人为秦国质子。公元前 247 年，嬴政即位，年仅十三岁，朝政由吕不韦把持。

**风格改写版（仿写，仅示范语感）**

> 公元前 259 年，邯郸城里生下一个男孩。
>
> 他爹异人，正在赵国当人质。这差事，说得好听叫质子，说得难听点，就是秦国押在赵国的一件抵押品。
>
> 男孩叫嬴政。
>
> 后来，他爹逃回秦国，做了秦王。三年后，爹死了，十三岁的嬴政即位。
>
> 十三岁，放在今天刚上初中。可在秦国，他已经是一国之君——虽然只是名义上的。
>
> 朝堂上真正管事的，是丞相吕不韦。

示范点：短句、现代参照、说书人旁白、心理与处境的推演、议论收束。事实仍以定稿史料表为准。

## 使用建议

- 先出分场稿，再做史料核对，最后才润色幽默和议论；顺序反过来容易为了金句改史实。
- 幽默和议论是最后一道工序，不要在初稿阶段堆太多。
- 同一集内保持一种叙述人称。第一人称适合自述体特辑，但标志性的“当年明月感”来自第三人称全知视角，两者不要混用。
- 风格是方法，不是口头禅。少用“历史就是这样”“不得不说”这类空转句，多用具体的人和事。
